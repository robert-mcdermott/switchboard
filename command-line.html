The command line tool

sbctl reads the same engine without the window, and is how most of Switchboard is tested. It travels inside the app:

/Applications/Switchboard.app/Contents/MacOS/sbctl top

From a clone, swift build && .build/debug/sbctl.

CommandWhat it does
sbctl topLive connections, busiest first
sbctl dumpThe engine's whole model as JSON
sbctl log query "process:Safari bytes>1MB" --since 7dSearch the log
sbctl log exportWrite the log as CSV or JSON lines
sbctl geo 8.8.8.8Where an address is and whose it is
sbctl trust /Applications/Safari.appWho signed a program
sbctl verifyCheck the engine against netstat and known traffic
