A fix to the installer. Apart from its version number and the scripts below, the app is the same as 0.1.0.

## Fixed

- **The installer refused some Macs with "the download does not match the release's checksum", when the download was fine.** It reported any failure of `shasum` as a mismatch. On a Mac with Intel-only programs left in `/usr/local/bin` by an old Homebrew, `shasum` cannot run at all without Rosetta, and Perl settings such as `PERL5LIB` can break macOS's own copy. The installer now uses only macOS's own tools. It says when the check could not run, and on a real mismatch shows what arrived instead.
- **The scripts inside the app use only macOS's own tools too.** These are the ones that install and remove the collector and download the location data, for anyone who runs them from a clone.

## Install or update

You need a Mac with Apple silicon (M1 or later) and macOS 15 or later. In Terminal:

```bash
curl -fsSL https://github.com/robert-mcdermott/switchboard/releases/latest/download/install.sh | bash
```

It installs Switchboard in /Applications, or updates 0.1.0. It updates a collector you already installed, which asks for your password; otherwise it asks whether to install one, and whether to download the location databases.

To install by hand, download `Switchboard-0.1.1-arm64.zip` below and drag Switchboard.app to Applications. It is not signed with a Developer ID or notarised, so macOS refuses to open it the first time. Open System Settings ▸ Privacy & Security and click **Open Anyway**. The Health tab then installs or updates the collector, and Settings ▸ Location downloads the location data.
