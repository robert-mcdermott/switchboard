The first release of Switchboard: a live picture of every network connection on your Mac, which program is talking, to whom, how much, and for how long.

This is a beta. It is used daily on the author's Mac, but has only been run on macOS 27.

## Install

You need a Mac with Apple silicon (M1 or later) and macOS 15 or later. In Terminal:

```bash
curl -fsSL https://github.com/robert-mcdermott/switchboard/releases/latest/download/install.sh | bash
```

The installer:

- puts Switchboard in /Applications, after checking the download against the SHA-256 written into it;
- asks whether to install the collector, which runs as root and lets Switchboard see every account's connections and their hostnames; it asks for your password;
- asks whether to download the free DB-IP Lite location databases, about 130 MB.

Run it again to update. Add `bash -s -- --uninstall` instead of `bash` to remove everything.

To install by hand, download `Switchboard-0.1.0-arm64.zip` below and drag Switchboard.app to Applications. It is not signed with a Developer ID or notarised, so macOS refuses to open it the first time. Open System Settings ▸ Privacy & Security and click **Open Anyway**. The Health tab then installs the collector, and Settings ▸ Location downloads the location data.

## What it does

- Every connection, by program: process, user, remote address and port, bytes and rate each way, age, TCP state, round-trip time.
- Hostnames from the DNS answers and TLS handshakes it sees, once the collector is installed.
- Country, city, and network owner for each destination.
- Who signed each program, and which destinations are new.
- Six layouts (Constellation, Flow, Lanes, Globe, Hierarchy, Cyberspace) and six colour themes.
- A filter language, a timeline you can drag back, and a searchable log you can export.
- `sbctl`, a terminal viewer, at `/Applications/Switchboard.app/Contents/MacOS/sbctl`.

It watches and never blocks or changes anything. It sends nothing anywhere. It uses the network itself only when you ask it to: to download the location data, or for reverse DNS lookups if you turn them on.

## Known limits

- Without the collector, macOS withholds about 5 to 8% of your own account's connections from Switchboard. It also reports other programs' new connections a few seconds late.
- The app uses 12 to 17% of a core in the Operator profile, over its 10% budget.
- It has run for hours at a stretch, not days. Memory with an hour of history is about 315 MB and still creeps up slowly.
- QUIC connections get names from DNS only. Encrypted DNS, ECH, and Private Relay all reduce what can be named.

## Files

- `Switchboard-0.1.0-arm64.zip`: the app, with the collector and `sbctl` inside it.
- `install.sh`: the installer.
- `SHA256SUMS`: checksums of both.

`install.sh` and `SHA256SUMS` were replaced on 24 November 2026; the zip is unchanged. The first installer reported a checksum mismatch whenever its check could not run, as on Macs with Intel-only tools left in `/usr/local/bin`. The new one uses only macOS's own tools and says why a check failed.
