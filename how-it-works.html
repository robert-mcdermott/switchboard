How it works

PartRole
SwitchboardCoreThe engine: connections, rates, names, the filter language. No system calls; fully testable
SwitchboardSourcesWhere data comes from: the system's network statistics, the kernel socket list, packet capture, process details
switchboarddThe optional root collector
SwitchboardStoreThe log, on the SQLite that ships with macOS
SwitchboardRenderThe graph, in Metal
SwitchboardAppThe window, in SwiftUI
sbctlDiagnostics

Some of the data comes from interfaces Apple does not document (the NetworkStatistics framework, the kernel socket list, PKTAP). Each is isolated, optional at run time, and reported on the Health tab, so a macOS update that breaks one costs detail rather than the app.

The full design is in docs/SPEC.md. What was measured, and what was not, is written up per milestone in docs/spikes.
